UAMSWP Video Directory is developed and maintained by UAMS Web Services in [UAMS-Web/UAMSWP-Video-Directory](https://github.com/UAMS-Web/UAMSWP-Video-Directory).

- **Report a problem or ask for a feature** in the repository's [issues](https://github.com/UAMS-Web/UAMSWP-Video-Directory/issues).
- **Releases** are listed on the [releases page](https://github.com/UAMS-Web/UAMSWP-Video-Directory/releases), each with its notes.
- **Running the tests and the code-quality tools** is covered in the [README](https://github.com/UAMS-Web/UAMSWP-Video-Directory#running-the-tests).
- **Contributing:** the path from an issue to a merged pull request is in [CONTRIBUTING.md](https://github.com/UAMS-Web/UAMSWP-Video-Directory/blob/master/CONTRIBUTING.md).

## These pages

The wiki is published from [`docs/wiki/`](https://github.com/UAMS-Web/UAMSWP-Video-Directory/tree/master/docs/wiki) by the *Publish wiki* workflow, which runs when a release is published and can be run by hand. Each run replaces every page with the folder's copy, so a page edited in the browser is overwritten: change the files in the folder through a pull request instead.
